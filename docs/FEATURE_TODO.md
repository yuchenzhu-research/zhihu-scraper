# 功能范围与后续待办

> 状态：2026-09-05 文件优先版本。`[x]` 表示代码、测试和公开文档已经形成闭环；`[ ]` 表示明确延期。

## 1. 项目定位

- 第一目标：作为工程化爬虫项目展示，功能真实可用、测试充分、容易解释。
- 第二目标：满足个人长期归档知乎内容的需要。
- 面向研究项目架构的开发者，以及希望由 Codex 等 Agent 代为执行命令的普通用户。
- 不维护 TUI、云端账号、前端构建系统、数据库、搜索索引或知识图谱。

## 2. 已完成抓取目标

- [x] 单篇专栏文章，并保存所属专栏信息
- [x] 单个回答
- [x] 问题详情及全部可访问回答，按分页合并为一个文档
- [x] 整个专栏及其全部可访问文章
- [x] 独立知乎视频（`zvideo`）
- [x] 文章或回答中的知乎视频卡片：解析直连视频，失败保留原链接并显示警告
- [x] 可选的一级评论与二级回复

当前不支持：

- 专栏合集
- 作者主页及其全部内容
- 搜索结果
- 想法、收藏夹、盐选等其他内容

## 3. 默认抓取内容

- [x] 标题、作者、原始链接和时间信息
- [x] 可获得的赞同数、回答数等来源统计
- [x] 段落、标题、列表、引用、表格、代码和超链接
- [x] TeX 公式；Markdown 保留 TeX，HTML 本地转换为 MathML
- [x] 图片、动图、封面和独立视频媒体
- [x] 文章与专栏、回答与问题的可读来源信息
- [x] 默认 Markdown；可选静态 HTML 与离线 PDF（支持 PDF-only）

HTML、PDF 和评论默认关闭，不属于普通抓取。只有 `--html` 或 `html = true` 才生成离线 HTML；只有 `--pdf` 或 `pdf = true` 才生成 PDF；只有 `--comments` 或 `comments = true` 才会抓取最多 10 条一级评论及每条最多 10 条二级回复，不足时保存全部。

项目不提供 SQLite、其他数据库、原始 JSON、搜索索引或知识图谱。归档内容只由 Markdown、媒体和按需生成的 HTML/本地样式、PDF组成。

## 4. 输出结构

整个专栏的默认结构：

```text
知乎归档/
└── 机器学习/
    ├── 机器学习.md
    ├── 内容/
    │   ├── 一文归纳AI数据增强之法.md
    │   └── ...
    └── media/
```

单篇文章、单个回答、整个问题和独立视频的默认结构：

```text
知乎归档/
└── 标题/
    ├── 标题.md
    └── media/
```

开启 HTML 后，同级增加同名 `.html` 和 `assets/`，专栏中的文章也增加对应 HTML。开启 PDF 后，目录与文章各增加同名 `.pdf`；单独 PDF 输出不会留下 HTML/样式中间文件。

- [x] 专栏同名文件保存简介和按年份分组的完整目录
- [x] 使用“本栏目共 N 篇”
- [x] 文章页提供所属专栏、返回目录和上一篇/下一篇导航
- [x] 不使用 `index.md` 或 `index.html`
- [x] 跨平台安全、优先可读的文件名
- [x] 按稳定知乎 ID 复用已有归档，重命名不创建副本
- [x] 封面/媒体源变化时更新引用，专栏完成正文保存后才发布目录
- [x] PDF 原文出处与可移动的专栏相对导航

## 5. 已确定默认值

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| Markdown | 开 | 生成可读 `.md` |
| HTML | 关 | 只能通过设置或 `--html` 开启 |
| 媒体下载 | 开 | 图片、动图、封面、独立视频 |
| PDF | 关 | 设置或 `--pdf` 开启，需要 Chrome 或管理 Chromium |
| 评论 | 关 | 只能通过设置或 `--comments` 开启 |
| 一级评论 | 10 | 不足 10 条时保存全部 |
| 每条二级回复 | 10 | 不足 10 条时保存全部 |
| 浏览器回退 | `auto` | HTTP/API 失败或载荷无效时回退 |
| 请求基础间隔 | 0.5 秒 | HTTP 客户端连续请求之间等待，可设为 0 |
| 请求随机抖动 | 0.5 秒 | 每次额外等待 0～0.5 秒，可设为 0 |
| 代理 | 关 | 配置后应用于 HTTP、管理浏览器和媒体 |

关闭评论或媒体表示本轮不请求对应可选数据。重复归档会按本轮结果重写 Markdown/HTML/PDF，不从隐藏状态恢复旧内容。已存在的媒体文件不会被主动删除。
